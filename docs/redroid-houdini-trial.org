#+title: Isolated Houdini trial on hypie

This trial starts a second Android container manually. It does not reconfigure
Guix System, replace =redroid-maa=, or reuse that container's game data. The
branch is based on main and does not include the experimental NDK EXEC patch.

* Deploy from lappie

In the repository checkout on lappie:

#+begin_src sh
git fetch origin
git switch --track origin/redroid-houdini-trial
scp scripts/redroid/start-houdini-test hypie.home.labbies.wenxinwang.me:/tmp/uraj-start-houdini-test
ssh -t hypie.home.labbies.wenxinwang.me 'sudo sh /tmp/uraj-start-houdini-test'
#+end_src

The script requires the existing =redroid= Docker network and =redroid-maa=
container configuration. It reuses their host init helper and Intel render
node. It pulls about 961 MB, then starts =redroid-houdini-test= at
=10.203.0.3:5555= with a fresh named volume, =redroid-houdini-test-data=.
No host ports are published. The existing bridge's egress policy still applies.
An occupied address, existing test container, or existing test volume causes
the script to stop instead of silently reusing it.

After startup, ADB on hypie can connect directly:

#+begin_src sh
adb connect 10.203.0.3:5555
adb -s 10.203.0.3:5555 shell getprop sys.boot_completed
#+end_src

Android initially has no game or account data. Install the same official APK,
verify the selected native bridge and actual loaded library, then test cold
starts and login while monitoring screenshots, process exit and CrashSight
records. Do not count an unchanged loading screenshot as success. Only proceed
to MAA account tasks after startup and login work.

The startup script has been syntax checked; container boot has not yet been
validated because the agent session lacks host Docker access.

* Stop and remove

On hypie, stop the trial without affecting the original container:

#+begin_src sh
sudo docker stop redroid-houdini-test
#+end_src

To resume the same test later, use =sudo docker start redroid-houdini-test=.
It has no automatic restart policy. When finished, these commands remove the
trial container and permanently discard only its game/account data:

#+begin_src sh
sudo docker rm redroid-houdini-test
sudo docker volume rm redroid-houdini-test-data
#+end_src
