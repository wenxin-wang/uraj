# Uraj, the code in public

...with lots of AI slop. In many, or most, cases, AI knows better than I do,
and works much harder, so it's fine with me.

This mono repo currently holds:

- Guix infrastructure for my systems. Thank god that AI knows about guix.
- Dotfiles. Yes, another repo for my dotfiles. More repos to archive.
- My emacs config.

The repo follows the structure promoted in https://trop.in/blog/a-sane-directory-structure-for-software-projects,
just to give it a try.

Start from [AGENTS.md](AGENTS.md): the directory and module tables, the
documentation rules and the entry points.  Documents live under
[docs/](docs/), terms are defined in [docs/glossary.md](docs/glossary.md).

The name comes from the Uraj crystal in StarCraft.
